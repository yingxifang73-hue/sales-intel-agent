# 报告聚焦与自定义行业设计

## 已确认的交互

- 生成页改为参考图的简洁进度卡：局部深色边框进度、小加载圈、标题、说明、进度数字和当前阶段；不显示大号百分比或蓝色断裂边框。
- 历史报告采用轻量列表，弱化外框，使用淡分隔线与单行打开操作。
- 联系方式只保留优先入口、电话邮箱、线下地址、推荐联系角色；删除真实公开联系人和信息说明侧栏，所有卡片左对齐。
- 删除产品匹配中的不稳定数量类指标，例如“匹配机会数 0”。
- 第七章备注整体删除，包括目录、页面与打印。
- 左上品牌不收缩、不换行，并在所有页面保持相同尺寸。
- 行业从原生 select 改为可搜索的 Notion 式菜单，包含常用行业和“自定义行业”；自定义文本传入后端研究上下文。

## 机会与痛点规则

1. 优先基于目标公司的官网/新闻/外部公开证据输出机会信号、待确认痛点、我方切入点与首次沟通问题。
2. 若公开资料不足以形成公司专属机会，仍必须输出一条“首轮待验证切入点”：只引用用户产品、行业和已知公司概况，不宣称客户已经存在采购需求或痛点。
3. 该切入点的措辞必须使用“待确认”“建议沟通验证”等限定；其作用是保证销售可以开场，而不是伪造客户事实。

## 验收

- 生成页视觉不再有蓝色断裂边框，并符合参考图的紧凑层级。
- 联系方式与报告目录没有被删除模块的入口。
- 报告总有机会与痛点章节内容；其内容可追溯为公开信号或明确的待验证切入点。
- 输入任意自定义行业后，后端和模型上下文均可收到该文本。
- 桌面和窄屏下，品牌、报告身份栏与卡片不会压缩变形。
