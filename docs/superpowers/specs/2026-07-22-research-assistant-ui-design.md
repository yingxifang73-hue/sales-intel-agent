# AI 销售研究助手界面设计

## 目标

将现有 Demo 改造成参考图所示的销售研究产品界面，同时让所有可见导航和操作具备真实可用行为。

## 视觉方向

采用柔和的自然商务风格：暖浅色背景、深苔绿色主色、圆角白色信息卡片、宽松留白和清晰的中文层级。首页聚焦一次调研输入；报告页采用左侧应用导航、中部报告内容和右侧调研辅助信息。

## 页面与交互

### 首页

- 顶部显示品牌和三个事实说明：公开信息、合规使用、约 30 秒。
- 主页使用居中标题、行业标签、横向输入卡片和三个价值点。
- 保留现有产品档案展开区及流式调研流程。

### 报告页

- 左侧栏提供新建调研、工作台、历史记录和个人主页四个可点击入口。
- 中部展示真实的目标公司、行业、网址、调研时间、报告目录和当前报告内容。
- 右栏显示基于当前报告计算的证据数量、完成状态、匹配度和耗时；无实际数据的字段不伪造。
- 历史记录显示当前浏览器真实保存的调研记录；点击任意记录打开对应报告。
- 个人主页展示并编辑已保存的产品档案。

## 本地数据

- 每次调研成功后，将报告、输入摘要和创建时间保存到浏览器 localStorage。
- 历史记录持久化于同一浏览器；无历史时使用明确空状态，不显示虚构公司。
- 当前选中的历史报告可从侧栏和右栏打开。

## 操作

- 导出 PDF 调用浏览器打印流程，打印样式隐藏应用导航和无关控件。
- 分享报告调用 Web Share；浏览器不支持时复制基于当前报告生成的摘要文本，并提示用户。
- 所有主导航、目录、历史项、产品档案编辑和返回动作均可点击且改变页面状态。

## 约束

- 不改动采集、模型、MCP、流式事件和证据质量逻辑，除非展示层为保存报告需要读取其已有字段。
- 不展示虚构客户、虚构报告统计或虚构历史。
- 桌面端对齐参考图；小屏幕改为可折叠/横向滚动的可读布局。
