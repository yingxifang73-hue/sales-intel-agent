# 客户调研工作台 UI 设计

## 目标

让销售人员在生成报告前只看到清晰的调研入口；报告生成后才进入能够实际浏览和切换的销售准备工作台。

## 页面状态

### 1. 调研入口

- 不显示左侧报告导航，因为此时没有报告可查看。
- 不使用大面积外框包住空白区域。
- 页面只保留产品名称、说明、官网、行业预设、销售方产品和生成按钮。
- 输入区为一张内容紧凑的表单卡；说明文字和表单不嵌套在多层卡片中。

### 2. 报告工作台

- 仅在接口成功返回报告后显示。
- 顶部显示目标公司域名、行业预设、销售方产品和“开始新调研”。
- 模块导航显示为横向报告目录：调研总览、公司画像、业务判断、销售准备、来源证据。
- 点击目录必须切换正文；目录当前项与正文标题一致。
- 总览显示客户概览、下一步建议、证据数量、优先信号和模块入口。
- 详情页为完整内容宽度，不再让左侧大栏与右侧大卡片挤占空间。

## 视觉规则

- 使用现有冷灰、近黑、蓝色重点色；移除调研前的黑色侧栏和白色巨大容器。
- 调研前以留白建立层级；报告后以细分割线和少量信息卡组织内容。
- 开发环境的 Next.js 调试浮标不属于产品。Demo 运行方式改为生产预览，页面不显示该标识。

## 验收

1. 初始页面没有报告导航，也没有 Next.js 调试浮标。
2. 成功生成报告后，五个导航项都能进入对应的报告内容。
3. 在任一详情模块点击“返回总览”能回到总览。
4. 桌面和移动端内容不重叠，表单可正常提交。
