# 销售调研 Agent：可读性、资料覆盖与报告交互改造

## 目标

将现有四个页面升级为适合大屏使用的、克制的苹果式产品后台；同时修复公开资料采集与展示链路，使公司概况、规模能力、联系方式、地址等信息在有公开证据时能够被采集、验证并展示。

## 已确认的体验决策

- 删除报告头部的“报告状态”字段，不展示“未达标”等标签。
- 桌面端正文最大宽度提升到约 1480px；报告使用更大的阅读字号，而非 12px/13px 的表格字号。
- 全局采用系统 San Francisco / PingFang 字体栈、较大字重层级、14–18px 圆角、白色卡片、浅灰背景、克制阴影和统一蓝色主操作。
- 输入、生成、报告和联系方式四页都使用同一套尺寸、颜色、卡片和按钮规则。
- 报告的可折叠章节默认收起；点击左侧目录时先展开目标章节，再将“数字＋标题”滚动到顶部。
- 不再展示“原始信息”“查看证据”“证据抽屉”等面向终端用户的来源入口；证据仍保留在内部数据中供模型校验。

## 资料链路修复

1. 联系页、地址、官方商城/公众号等页面不再被搜索候选过滤；它们会作为联系方式专用证据采集。
2. 模型证据包由 8 条 × 1000 字扩展为按类别保留公司、规模、联系、产品和动态等关键正文，并避免将官网详情挤出上下文。
3. 对直接可验证的邮箱、电话、地址、联系页采用确定性提取作为模型提取的补充；只输出来源正文中真实存在的值。
4. 报告历史保留既有数据；新链路只影响后续重新调研。旧报告不会被伪造性补全。

## 验收标准

- 1920px 宽度下，输入页和报告页不再出现大面积无效空白；正文和卡片信息一眼可读。
- 报告头部无“报告状态”字段，长公司名/产品名/日期不再出现截断胶囊。
- 联系方式页有公开联系方式时展示；无时明确说明“未找到”，不虚构。
- 点击目录第 2–7 节时，目标章节展开且标题可见。
- 单元测试、类型检查、静态检查、生产构建通过；使用浏览器截图核对输入页、生成页、报告页和联系方式页。
