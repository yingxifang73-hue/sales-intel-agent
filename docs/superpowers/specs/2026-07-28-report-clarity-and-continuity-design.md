# 报告清晰度、持续调研与历史页统一设计

## 目标

让销售调研在后台持续执行，报告只展示可读、中文化且对销售有用的信息；消除空白占位、抓取日志和“AI 判断”视觉标签，并将历史报告页统一为同一套大字号、宽内容区、圆角卡片的产品界面。

## 界面与交互

- 生成页使用一个沿圆角报告卡片边框运行的 SVG 进度环，显示百分比与当前阶段摘要。
- 调研请求由根页面状态持有。用户可在调研中进入历史页或返回输入页；请求、事件接收和最终保存不因视图切换而中断。完成时自动进入新报告。
- 左侧导航从当前窄栏扩展为 280px，增加文字、图标、可点击区域和分组间距；输入、历史、详情页面共享此尺度。
- 历史页使用宽内容区、28px 标题、16px 正文、圆角记录卡片/表格与统一的蓝色主操作，不保留小字号旧表格样式。
- 不渲染任何 `AI 判断` 徽标。事实与分析仍保留在数据中，但通过确定性中文标题和谨慎措辞表达。
- 不再提供“详情”按钮；报告项直接使用短标题、结论、要点的结构化内容，避免原始正文整段堆积。

## 报告内容规则

- 第七章更名为“备注”，仅保存已检索、但未归入六个正式模块的业务信息；删除抓取工具名称、来源统计、模型阶段、失败日志和技术审计文本。
- 客户画像以“公司概况、产品与服务、目标市场、商业模式、产品定位、规模与能力、近期动态”组成。只有有实际内容的卡片显示；不能显示“当前信息不足”的空卡片。
- 数据管道先从官方、新闻、招聘、行业和公司相关外部资料中收集证据，再由模型把原文清洗、翻译成中文、压缩为字段化结论。模型只能基于已采集证据归纳，不能编造公司事实、联系人或规模。
- 非模块资料进入备注前先剔除导航、Markdown 标记、重复句和技术日志；每条备注只保留一个中文标题和不超过两条事实要点。

## 验收标准

1. 调研中切换至历史页再返回，进度继续变化；完成后生成一条可打开的历史记录。
2. 生成页可见沿卡片圆角边界运行的进度，而不是中央旋转图标。
3. 报告、输入、历史页均使用一致的大字号、宽内容区、圆角卡片和统一按钮。
4. 页面无 `AI 判断`、`详情`、`Firecrawl`、`Jina`、`模型阶段` 等用户可见的技术性文本。
5. 对没有可靠数据的客户画像细项，不出现空白提示卡；有采集到的数据时显示中文、结构化摘要。
6. 既有历史报告不被伪造或篡改；新调研使用强化后的清洗与归纳链路。
